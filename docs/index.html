Keeps your secrets out of AI coding agents

Cloakroom swaps your secrets and personal data for placeholders before your AI coding agent sees them, and puts the real values back in the files it writes.

Mac, Windows and Linux. Inside Claude Code:

/plugin marketplace add shanjeevrajendran/cloakroom
/plugin install cloakroom@cloakroom

Mac and Linux. In a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install codex

The part in brackets adds the AI model that finds names and addresses on your machine, and reading text in screenshots and scans.

Mac and Linux. In a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install gemini

The part in brackets adds the AI model that finds names and addresses on your machine, and reading text in screenshots and scans.

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install cursor

Secrets means API keys, passwords and tokens. Each highlighted label the agent sees is a placeholder: it takes the real value’s place. The agent works with the placeholder; the real value stays on your machine.

The first start downloads a small AI model once, to spot names and addresses (about 1 GB on a Mac, up to about 4 GB elsewhere). After that, nothing leaves your machine.

The agent can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values.

What it does

Hides your data before the agent sees it

Keys and passwords with a known pattern, card and ID numbers, and names, emails, addresses and birth dates in ordinary sentences. A small AI model on your machine finds the ones with no fixed pattern.

Puts the real values back in files it writes

Each value it finds is swapped for a placeholder. When the agent writes a file or runs a command that contains a placeholder, the real value goes back in, on your machine, just before it runs.

Learns from your corrections

When it hides something harmless (a false alarm), mark it once in the dashboard and a rule stops it next time. The AI model itself never changes. Your labels become rules that run before it.

Common questions

Does Cloakroom send my data anywhere?

No. It downloads its AI model once from Hugging Face, and everything else runs on your own machine.

What does it mask?

API keys, passwords, tokens and personal data such as names, emails and addresses. Text in scanned pages and photos is read on your machine and hidden like any other file.

Does the agent still work normally?

Yes. The agent works with placeholders, and the real values are put back, on your machine, in the files the agent writes.

What happens when my prompt contains a secret?

Cloakroom can stop a prompt but can’t edit it, so it stops it and tells you what it found. Put the detail in a file and ask the agent to read it instead.

Does Cloakroom work with Codex, Gemini CLI or Cursor?

Yes, on Mac and Linux: run cloakroom install codex, cloakroom install gemini or cloakroom install cursor (Cursor’s terminal agent; the editor isn’t checked yet). Claude Code works on Mac, Linux and Windows.

Can the agent switch Cloakroom off?

No. It can’t approve a call Cloakroom held, remove Cloakroom, or add a hook (a command it runs by itself) or an MCP server (an add-on tool) to its settings. Those wait until you type cr: allow, or run the command in your own terminal.

What is stored and what leaves my machine?

The Security page lists what Cloakroom keeps, where it keeps it, what leaves your machine and what it cannot catch.

What doesn't it protect?

It stops accidental leaks, like a key in a file the agent happened to open. It isn’t a sandbox (a sealed-off space the agent can’t get out of). Out of scope:

  • an agent taken over by hidden instructions (a prompt injection) that sneaks data out a piece at a time. Cloakroom limits the rest of what such an agent can do: it only has placeholders, secrets Cloakroom has seen are held on the way out, and it can’t approve its own held call or switch Cloakroom off
  • what you type into a prompt, which Cloakroom can stop but not edit
  • Claude Code’s own logs on your disk

How I keep secrets and personal data out of Claude Code

What the agent sees

Claude Code lets a plugin run hooks: small checks before and after every action Claude takes, such as reading a file or running a command. Cloakroom runs in those hooks. When Claude reads a file or runs a command, the output goes through Cloakroom first. It looks for:

  • secrets with a known shape (cloud keys, tokens, private keys, passwords in URLs and config lines)
  • numbers with a built-in check digit (cards, IBAN bank account numbers, US Social Security numbers)
  • personal data in ordinary text (names, emails, addresses, birth dates), found by a small AI model that runs on your machine

Each value it finds is swapped for a placeholder. Here’s a support note and a config line, on disk and as Claude gets them:

# on disk
Nadia Petrov called about a double charge. Reach her at nadia.petrov@gmail.com, 18 Larkspur Lane, Charlotte NC.
DATABASE_URL=postgres://admin:Hunter2x9@10.0.4.12/prod

# what the agent sees
PII_PERSON_1 called about a double charge. Reach her at PII_EMAIL_1, PII_ADDRESS_1.
DATABASE_URL=postgres://admin:PII_SECRET_1@10.0.4.12/prod

Claude can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values. A value keeps the same placeholder for the whole session, so the same person has the same placeholder in every file.
