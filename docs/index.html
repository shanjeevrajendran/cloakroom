Keeps your secrets out of AI coding agents

For developers who use an AI coding tool in a terminal: Claude Code, Codex CLI, Gemini CLI or Cursor’s terminal agent. It does not cover browser chats or the Cursor editor.

Cloakroom swaps your secrets and personal data for placeholders before your AI coding agent sees them, and puts the real values back in the files it writes.

Mac, Windows and Linux. Inside Claude Code:

/plugin marketplace add shanjeevrajendran/cloakroom
/plugin install cloakroom@cloakroom

Mac and Linux. In a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install codex

The part in brackets adds the local detection model and reading text in pictures.

Mac and Linux. In a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install gemini

The part in brackets adds the local detection model and reading text in pictures.

Cursor’s terminal agent (agent), not the editor. Mac and Linux.

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install cursor

The part in brackets adds the local detection model and reading text in pictures.

What the agent sees

A placeholder is a label like PII_PERSON_1. The AI works with the label; the real value never leaves your machine. First start downloads the detection model once (about 1 GB on a Mac, up to about 4 GB elsewhere). After that, nothing leaves your machine.

The agent can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values.

Hides your data before the agent sees it

Keys and passwords with a known pattern, card and ID numbers, and names, emails, addresses and birth dates in ordinary text. A small AI model on your machine finds the ones with no fixed pattern.

Puts the real values back in files it writes

Each value it finds is swapped for a placeholder. When the agent writes a file or runs a command that contains a placeholder, the real value goes back in, on your machine, just before it runs.

Learns from your corrections

When it masks something harmless (a false alarm), mark it once in the dashboard and a rule stops it next time. The detection model itself never changes. Your labels become rules that run before it.

Common questions

Does Cloakroom send my data anywhere?

No. It downloads the detection model once from Hugging Face, and everything else runs on your own machine.

What does it mask?

API keys, secrets and personal data such as names, emails and addresses. Scanned pages and photos are read on your machine and masked like any other file.

Does the agent still work normally?

Yes. The agent works with placeholders like PII_PERSON_1, and the real values are put back, locally, in the files Claude writes.

What happens when my prompt contains a secret?

A prompt can be blocked but not rewritten, so Cloakroom stops it and tells you what it found. Put the detail in a file and ask Claude to read it instead.

Does Cloakroom work with Codex, Gemini CLI or Cursor?

Yes, on Mac and Linux: run cloakroom install codex, cloakroom install gemini or cloakroom install cursor (Cursor’s terminal agent; the editor isn’t checked yet). Claude Code works on Mac, Linux and Windows.

What is stored and what leaves my machine?

The Security model lists what is stored, where, what leaves your machine and what it cannot catch.

What doesn't it protect?

It stops accidental leaks, like a key in a file the AI happened to open. It isn’t a sandbox that walls the AI off. Out of scope: hidden instructions in a file (a prompt injection) that trick the AI into leaking data piece by piece; what you type into a prompt, which Cloakroom can stop but not rewrite; and Claude Code’s own logs on your disk.

How I keep secrets and personal data out of Claude Code

What the agent sees

Claude Code lets a plugin run hooks: small checks before and after every action Claude takes, such as reading a file or running a command. Cloakroom runs in those hooks. When Claude reads a file or runs a command, the output goes through Cloakroom first. It looks for:

  • secrets with a known shape (cloud keys, tokens, private keys, passwords in URLs and config lines)
  • numbers with a built-in check digit (cards, IBANs, SSNs)
  • personal data in ordinary text (names, emails, addresses, birth dates), found by a small AI model that runs on your machine

Each value it finds is swapped for a placeholder. Here’s a support note and a config line, on disk and as Claude gets them:

# on disk
Nadia Petrov called about a double charge. Reach her at nadia.petrov@gmail.com, 18 Larkspur Lane, Charlotte NC.
DATABASE_URL=postgres://admin:Hunter2x9@10.0.4.12/prod

# what the agent sees
PII_PERSON_1 called about a double charge. Reach her at PII_EMAIL_1, PII_ADDRESS_1.
DATABASE_URL=postgres://admin:PII_SECRET_1@10.0.4.12/prod

Claude can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values. A value keeps the same placeholder for the whole session, so PII_PERSON_1 in one file is the same person in the next.

I’d like to hear what it misses and what it over-masks: https://github.com/shanjeevrajendran/cloakroom
