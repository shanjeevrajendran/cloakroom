Keeps your secrets out of AI coding agents

Cloakroom swaps your secrets and personal data for placeholders before your AI coding agent sees them, and puts the real values back in the files it writes.

Inside Claude Code:

/plugin marketplace add shanjeevrajendran/cloakroom
/plugin install cloakroom@cloakroom

Codex CLI (Mac and Linux), in a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install codex

Gemini CLI (Mac and Linux), in a terminal:

uv tool install "cloakroom[model,torch,ocr]"
cloakroom install gemini

Star on GitHub 40-second demo (Claude Code)

What Claude sees

A placeholder is a label like PII_PERSON_1. The AI works with the label; the real value never leaves your machine.

Claude can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values.

Catches personal data

Keys and passwords with a known pattern, card and ID numbers, and names, emails, addresses and birth dates in ordinary text. A small AI model on your machine finds the ones with no fixed pattern.

Masks, then puts values back

Each value it finds is swapped for a placeholder. When Claude writes a file or runs a command that contains a placeholder, the real value goes back in, on your machine, just before it runs.

Learns from your corrections

When it masks something harmless (a false alarm), mark it once in the dashboard and a rule stops it next time. The detection model itself never changes. Your labels become rules that run before it.

Shows which keys your agents saw

cloakroom exposure lists the keys and passwords Claude Code, Codex CLI and Gemini CLI saw, each as a hint (ghp_…LmPq), never the key, and ends with a “Rotate these” list. It lists only what Cloakroom detected.

Warns when a pull changes what your agent runs

cloakroom scan lists every command a repo’s agent and editor config would run and flags the npm worm’s shape. After cloakroom install git-hook, each pull, checkout or merge that adds or changes such a command prints it. It warns, never blocks.

Hand the agent a key safely

cloakroom give NAME asks for the value in a hidden terminal prompt and gives you a placeholder to paste. When the agent writes that placeholder into a local file or command, the real value goes back in. The AI never sees it.

Shows where your agent sends data

cloakroom report --destinations lists the hosts your agent’s commands, web fetches and MCP calls went to, with the kinds of data they carried, and the dashboard shows the same in “Where data went”. cloakroom allow-host example.com builds an approved-sites list; once it is on, a call to any other site is held. An email, phone number, name or your username in a web address or header is held too.

Points any tool at Cloakroom

cloakroom proxy is a small server on your own machine for tools that let you set their API address, such as Claude Code, Codex CLI and Gemini CLI. Point the tool at it and every request is masked before it goes to the AI company, with streaming left alone. Off until you start it; Mac, Linux and Windows.

Updates with one command

Run cloakroom update in a terminal. It updates Cloakroom with the installer you used (uv, pipx or pip) and keeps the optional parts you had. Then it sets up Cloakroom’s checks again for Codex, Gemini CLI and git commits, only where they were set up before.

Takes stopped prompts out of the saved chat

Claude Code also saves every chat on your disk. A prompt Cloakroom stops is taken out of that saved copy for the current session (right away, after the next reply and when the session ends), so the key you typed doesn’t stay behind. Claude Code only.

Counts failed tool calls as not checked

A tool call that fails in Claude Code (for example a command with a non-zero exit) is counted as “not checked”: it shows in the event log, in “Checks skipped” in cloakroom report, on the dashboard, and as one note per session.

Install

Free and open source. It works with Claude Code, Codex CLI and Gemini CLI (AI coding agents that run in a terminal) and sets itself up on first start. Claude Code runs on Mac, Windows and Linux; Codex and Gemini on Mac and Linux.

Inside Claude Code:

/plugin marketplace add shanjeevrajendran/cloakroom
/plugin install cloakroom@cloakroom

Restart Claude Code and Cloakroom sets itself up: keys, card numbers and ID numbers are covered within seconds if uv or pipx (tools that install Python programs) is already installed, or in about a minute when Cloakroom has to download them first; names and addresses a few minutes later, once the detection model has downloaded.

Using Codex CLI or Gemini CLI (Mac and Linux)? Install the program with uv tool install "cloakroom[model,torch,ocr]", then run cloakroom install codex or cloakroom install gemini.

Common questions

Does Cloakroom send my data anywhere?

No. It downloads the detection model once from Hugging Face, and everything else runs on your own machine.

What does it mask?

API keys, secrets and personal data such as names, emails and addresses. Scanned pages and photos are read on your machine and masked like any other file.

Does Claude still work normally?

Yes. Claude works with placeholders like PII_PERSON_1, and the real values are put back, locally, in the files Claude writes.

What happens when my prompt contains a secret?

A prompt can be blocked but not rewritten, so Cloakroom stops it and tells you what it found. Put the detail in a file and ask Claude to read it instead.

Does Cloakroom work with Codex or Gemini CLI?

Yes, on Mac and Linux: run cloakroom install codex or cloakroom install gemini. Claude Code works on Mac, Linux and Windows.

What is stored and what leaves my machine?

The Security model lists what is stored, where, what leaves your machine and what it cannot catch.

What doesn't it protect?

It stops accidental leaks, like a key in a file the AI happened to open. It isn’t a sandbox that walls the AI off. Out of scope: hidden instructions in a file (a prompt injection) that trick the AI into leaking data piece by piece; what you type into a prompt, which Cloakroom can stop but not rewrite; and Claude Code’s own logs on your disk.

How I keep secrets and personal data out of Claude Code

What Claude sees

Claude Code lets a plugin run hooks: small checks before and after every action Claude takes, such as reading a file or running a command. Cloakroom runs in those hooks. When Claude reads a file or runs a command, the output goes through Cloakroom first. It looks for:

  • secrets with a known shape (cloud keys, tokens, private keys, passwords in URLs and config lines)
  • numbers with a built-in check digit (cards, IBANs, SSNs)
  • personal data in ordinary text (names, emails, addresses, birth dates), found by a small AI model that runs on your machine

Each value it finds is swapped for a placeholder. Here’s a support note and a config line, on disk and as Claude gets them:

# on disk
Nadia Petrov called about a double charge. Reach her at nadia.petrov@gmail.com, 18 Larkspur Lane, Charlotte NC.
DATABASE_URL=postgres://admin:Hunter2x9@10.0.4.12/prod

# what Claude sees
PII_PERSON_1 called about a double charge. Reach her at PII_EMAIL_1, PII_ADDRESS_1.
DATABASE_URL=postgres://admin:PII_SECRET_1@10.0.4.12/prod

Claude can still do the job. It knows there’s a person, an email and a password, and where each one sits. It just doesn’t know the values. A value keeps the same placeholder for the whole session, so PII_PERSON_1 in one file is the same person in the next.

Try it

It’s open source, runs locally, needs no account, and works on macOS, Windows and Linux. Inside Claude Code:

/plugin marketplace add shanjeevrajendran/cloakroom
/plugin install cloakroom@cloakroom

It protects keys and card numbers within about a minute (seconds if uv or pipx is already installed), then downloads the local model in the background for names and addresses.

I’d like to hear what it misses and what it over-masks: https://github.com/shanjeevrajendran/cloakroom
